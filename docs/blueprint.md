# **App Name**: VidShare

## Core Features:

- Video Search and Filtering: Implement video search functionality with filtering based on tags, title, and other relevant metadata. This will use the Next.js API routes.
- Video Preview on Hover: Display video previews on hover.  This reduces the need to fully load the video, improving performance.
- AI-Powered Video Recommendations: Implement a 'Recommended Videos' section using a tool to suggest videos based on viewing history. Use AI to determine if a video is relevant to the user's viewing history, and present the video if it is deemed relevant.
- User Authentication and Authorization: Implement user authentication and authorization to manage user access and permissions.
- UPI Payment Integration: Integrate UPI payment gateway for seamless transactions.

## Style Guidelines:

- Primary color: Dark blue/gray for the dark mode base.
- Secondary color: Light gray/white for the light mode base.
- Accent: Teal (#008080) to highlight interactive elements and calls to action, providing a visual pop against the glassmorphic background.
- Clean and modern sans-serif font for readability.
- Use minimalist icons for navigation and video controls.
- Responsive layout with a top navigation bar and a left sidebar for filters.
- Subtle transitions and animations for a smooth user experience.
